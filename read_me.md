Aby zobaczyć pełną dokumentację należy wejść na stronę: http://localhost:3000/api-docs/#/, po uruchomieniu serwera.
Aby wejść na serwer, należy wejść na stronę: http://localhost:3000
Aby uruchomić w cmd:
- testy automatyczne, należy wpisać komendę: npm test
- serwer, należy wpisać komendę: npm start
